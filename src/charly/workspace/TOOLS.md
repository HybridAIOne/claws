# TOOLS.md - Local Notes

## Current Assumptions

- Prefer built-ins for web research, note drafting, and scheduled briefing prep.
- Use calendar, mail, docs, or dashboard connectors when the workspace has authenticated access and the briefing needs live context.
- Store briefing drafts, daily packets, and reminder notes in `deliverables/` when creating files.
- Timestamp briefing artifacts clearly because their value decays fast.

## Platform Tools

- `geo_sniffer` (HybridAI built-in, about 0.10 EUR per call on the user's credits): for a prompt, it shows which search queries ChatGPT, Claude or Gemini run (`asked`, `live`), which sites they cite (`sites`) and which brands they recommend (`brands`). Use it to measure prompt coverage, citation gaps and competitor mentions before recommending. Work with a focused prompt set rather than dozens of calls, and mention the cost when the user asks for a large batch.

## Reusable Reminders

- Relevance first.
- Sensitive claims need sources.
- A briefing should point toward a decision, not just summarize information.
